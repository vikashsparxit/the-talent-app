# Support

Thanks for using The Talent App. This page explains where to get help, whether you are self-hosting, contributing or need hands-on assistance.

## Before you ask

- Read the [self-hosting quickstart](docs/guides/oss-self-host.md) and the [local setup guide](docs/LOCAL_SETUP_GUIDE.md). They cover prerequisites, Supabase setup, migrations, edge function secrets and local development.
- Upgrading? Read [docs/UPGRADING.md](docs/UPGRADING.md) and the notes for your target release in [CHANGELOG.md](CHANGELOG.md).
- Search [existing issues](https://github.com/vikashsparxit/the-talent-app/issues) and [Discussions](https://github.com/vikashsparxit/the-talent-app/discussions).

## Where to go

| You need | Go to |
|---|---|
| Help with setup, configuration or usage | [Discussions → Q&A](https://github.com/vikashsparxit/the-talent-app/discussions/categories/q-a) |
| To report a reproducible bug | [Open a bug report](https://github.com/vikashsparxit/the-talent-app/issues/new/choose) |
| To suggest a feature | [Discussions → Ideas](https://github.com/vikashsparxit/the-talent-app/discussions/categories/ideas), or a feature request issue for a scoped proposal |
| To contribute a fix or feature | [CONTRIBUTING.md](CONTRIBUTING.md) |
| To report a security vulnerability | **Privately**, following [SECURITY.md](SECURITY.md). Never in a public issue. |
| To report a Code of Conduct concern | [opensource@sparxit.com](mailto:opensource@sparxit.com) |
| Commercial support, hosting or customization | [SparxIT](https://www.sparxitsolutions.com) |

When you ask for help, include your release version, how you deploy (self-hosted Supabase, Supabase Cloud or local), what you expected and what happened. Remove keys, passwords, hostnames and any candidate data first.

## What to expect

Community support is provided by the maintainers and other users on a best-effort basis. Maintainers aim to give a first response to new issues and pull requests within three business days. Only the latest release line is supported; see [SECURITY.md](SECURITY.md) for the security support window.
